The formula for Fibonacci:
T (a; b) = (a + b; a)

Is actually an instance of the transformation Tpq:
Tpq (a; b) = (bq + aq + ap; bp + aq)

In the instance where p=0 and q=1:
Tp=0 q=1 (a; b) = (1b + 1a + 0a; 0b + 1a) = (a + b; a)

Now, show that using this transformation twice when p=0 and q=1 is the same as
using it only once when p=1 and q=1 (the end state after using the
transformation one time). Considering that Tp'q' = Tp=1 q=1, show that
Tp=0 q=1(Tp=0 q=1) == Tp=1 q=1 == Tp'q'. Then, use this relationship to "square"
The Fibonacci transformation the same way you squared the base when constructing
the logarithmic time exponentiation procedure.

Demonstration:
Tp=0q=1(5 . 3) = ((+ (* 3 1) (* 5 1) (* 5 0)) . (+ (* 3 0) (* 5 1)))
               = ((+ 3 5 0) . (+ 0 5))
               = (8 . 5)

Tp=0q=1(8 . 5) = ((+ (* 5 1) (* 8 1) (* 8 0)) . (+ (* 5 0) (* 8 1)))
